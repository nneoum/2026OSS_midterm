# 캠퍼스 분실물 관리 - Frontend Midterm Starter

## 시작하기
- VS Code로 폴더를 엽니다.
- `index.html`을 브라우저 또는 Live Server에서 실행합니다.
- CSS Framework는 Bootstrap 5.3.3 CDN을 이미 연결했습니다. 인터넷 연결이 필요한 스타일이므로 감독자가 시험 전에 CDN 접속 여부를 확인해야 합니다.
- 서버, npm, DB 설치는 필요하지 않습니다.

## 파일과 역할
- index.html: Form / 목록 / 검색 요소
- style.css: 화면 레이아웃 및 사용자 정의 스타일
- app.js: 배열, 렌더링, 수정/삭제, 등록/검색 기능
- ANSWERS.md: 코드 설명 답안
